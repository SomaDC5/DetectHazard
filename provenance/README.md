# データの出自 — タイルごとに「いつのものか」

学習に使っている3つのデータは、**どれも単一の年のものではない。**

| | 出典 | 年の決まり方 |
|---|---|---|
| **DEM** | 国土地理院 基盤地図情報 5mメッシュ（航空レーザ測量）| **区画ごとに測量年度が違う** |
| **APM** | 国土地理院 地理院タイル `seamlessphoto`（全国最新写真・シームレス）| **複数時期の合成。地点ごとに撮影年が違う** |
| **マスク** | 国土数値情報 A33 土砂災害警戒区域（`A33_001=1` 急傾斜地の崩壊）| 版は1つだが、**区域ごとに指定年月日が違う** |

「古いデータのところで精度が落ちているのではないか」という問いは、
タイル単位でこの3つが分からないと答えられない。その表がここにある。

作るのは `analysis/run_tile_vintage.py`。

```bash
python analysis/run_tile_vintage.py --region hiroshima --dem    # GML を読む（1回でよい）
python analysis/run_photo_year.py  --region hiroshima --scan    # 地理院に取りに行く（遅い）
python analysis/run_tile_vintage.py --region hiroshima --build  # 表にする
```

## 列

| 列 | 内容 |
|---|---|
| `tile_no` | タイル番号（pkl の `No` と同じ）|
| `lon` / `lat` | タイル左上の経緯度 |
| `gt_pos` | 正解の画素数。0 なら背景タイル |
| `dem_survey_year` | **DEM の測量年度。** GML の `orgMDId`（`H24GC008` → 2012年度）|
| `dem_year_n` | そのタイルに掛かる測量区画の年度が何種類あるか。**2以上なら年度がまたがる** |
| `apm_photo_year` | **航空写真の撮影年度。** `nendophoto{年}` を新しい順に当てた結果 |
| `mask_year_min` / `mask_year_max` | **区域の指定年の範囲**（`A33_007`）|
| `mask_n_polygon` | そのタイルに掛かる区域ポリゴンの数 |

## 読むときの注意

**`devDate` は測量年ではない。** DEM の GML には提供日（2025-06-20 など）と
測量ID（`orgMDId`）の2つがあり、前者はダウンロードした版の日付にすぎない。
この表に入れているのは**測量年度のほう**である。

**マスクの年はタイル単位であって、かたまり単位ではない。**
ラスタ化後の連結成分と A33 のポリゴンは1対1に対応しないので、
分かるのは「そのタイルに掛かる区域の指定年の範囲」まで。
かたまりごとに正確に出すには、指定年を画素に焼き直す必要がある。

**`apm_photo_year` が空のタイルがある。**
地理院に取りに行くのが遅く（約1,000タイル/8分）、
いまはテスト集合だけ集めてある。評価に使うのはテスト集合なので実害はない。

**年度別レイヤとシームレス写真が同じものかは確認済み。**
`run_photo_year.py --verify` で40タイルを突き合わせ、
画素差の平均 2.5（0〜255）、全件が5未満だった。
つまり `apm_photo_year` は**学習に使った写真そのものの年度**である。

## これで答えられた問い

**「航空写真が古く、宅地開発が進んでいるところを見落としているのでは」**（2026-10-25）

指定基準に人家の有無が含まれるので、「指定が写真より後」の区域では
指定の原因になった宅地が写真に写っていない。そこが落ちるなら指摘が正しい。

同じ 2018 年度の写真の中だけで比べた結果（地域の性質が揃う）。

| 条件 | 指定が写真より**後** | 指定が写真より**前** | 差 |
|---|---:|---:|---:|
| 出発点 U-Net | 0.6394 (2,288件) | 0.6205 (2,103件) | **+0.0189** |
| +土地利用・OL学習 | 0.6783 | 0.6434 | **+0.0350** |
| PSPNet | 0.6534 | 0.6282 | **+0.0253** |

**3条件とも逆向きで、写真より後に指定された区域のほうが当たる。**
ゆらぎ幅 0.0071 の 2.7〜4.9 倍なので、帯の中ではない。
落ちているのはむしろ**古い指定**のほうで、2005〜2009年指定が箇所R 0.4670 と低い。
`analysis/run_designation_year.py` で再現できる。
