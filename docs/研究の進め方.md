| 2分岐デコーダ（予測を分割する後段）| 島根では伸びが帯を下回る。箇所R は1画素も動かない | `46.5`・`19` |
| DEM を3次元にする | 2次元で既に学べている。回転等変性はこの課題では有害 | `35` |
| 座標・bbox の直接予測 | 被覆方式の評価と噛み合わない | `箇所検出特化モデル案の検討.md` の `3.4` |
| 箇所F でモデルを選ぶ | 得失が釣り合わない | `実験のまとめ.md` の `4.5` |
| 2段目を AUC で選ぶ | AUC と箇所F の向きが逆転することがある | `15.6`・`23.6` |
| 島根の主系統を `gtonly` に変える | 島根は実運用の模倣なので `all` が正しい。揃えた値は補助 | `34` |
| 既存の重みに乱数の固定を入れて学習し直す | 15本以上の再学習になる。未学習のものだけ固定した | `ゆらぎ幅.md` の `8.3` |
| 背景タイルの偽陽性の深追い | 上限が小さい | `36` |

**候補として残してあるもの** ── `35` の Dual-Field（境界場と形状場の分離）は
2次元で書け、予測が隣の正解をまたいで繋がる弱点に直接当たる。

## 6. 進め方の作法

新しい実験を足すときは、この順で進める。

1. **問いを1つに絞り、成否を何で見るかを先に書く。** 和集合なら床、後処理なら帯の何倍か
2. **走らせる前に予測を書く**（`26` がその例。外れたら外れたと書く）
3. **学習なしで測れるものから先に測る。** 上限や床を出して、見込みが帯を下回るならやめる
   （`36`・`37`・`46.5` はこれで学習を省いた）
4. 条件は `tools/new_experiment.py` で作る。**既存のノートブックをコピーしない**
5. 測る前に分割を確かめる（`tools/audit_splits.py`）。**食い違ったら混ぜない**
6. 差は帯で割る。**幅の比**と**シードの範囲が重なるか**の2つで見て、食い違ったら両方書く
7. **1段目の帯を2段目の判定に流用しない**（2段目の帯は別に測ってある。`17`・`45.5`）
8. 数字を文書に書くなら記録する（`--record`）。**しきい値はテストで選ばない**
9. 測っていないことは「未検査」と書く。**間違いは消さずに訂正として残す**
10. 節の最後に「確かめていないこと」を書く

**外部データを足す方向は3回続けて空振りした**（広域・土地利用・建物を2段目に）。
効いたのは「モデル間の食い違い」（合意数）と「1段目の入力を変えた構成員」である。
**新しい情報を足すときは、それが1段目の内側に既にある量かどうかを先に疑う。**
