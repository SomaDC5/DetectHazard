## 2. ゆらぎの正体は停止エポックである

`1.1` の表を最良エポックで並べると、再現率と適合率が**完全に単調**になる。

| 最良ep | 面積R | 面積P | 面積F |
|---|---|---|---|
| 32（シード2） | **0.7345** | 0.6195 | 0.6721 |
| 38（シード3） | 0.7218 | 0.6314 | 0.6736 |
| 42（シード1） | 0.7104 | 0.6410 | 0.6739 |
| 48（出発点） | 0.6833 | **0.6625** | 0.6727 |

| 指標 | 停止エポックに対する傾き | 相関 |
|---|---|---|
| 面積R | **−0.00318 / epoch** | **r = −0.981** |
| 面積P | **+0.00267 / epoch** | **r = +0.988** |
| 面積F | +0.00004 / epoch | r = +0.324 |

**シードが直接ゆらぎを生んでいるのではない。**
シードが変わると検証F最良エポックが 32〜48 のどこに落ちるかが変わり、
**それが動作点（再現率と適合率のどちらに寄るか）を決めている。**
F値はこの軸に対してほぼ平坦なので、動作点が動いてもF値は動かない。

> 検証F最良エポック自体のF値は 0.6667〜0.6691（幅 0.0024）で、
> **どのエポックで止めても検証F上はほぼ同じ**である。
> 検証Fはこの動作点の差を区別できていない。

### 2.1 これは alpha を振ったときと同じ現象である

`展望_再現率をどう上げるか.md 11` で、FocalTversky の alpha を 0.5→0.85 に
振っても**面積は増えるが箇所は増えない**（面積比 1.031→1.165、箇所比 0.924→0.913）
ことを測っていた。停止エポックでも同じ方向に動く。

| | 予測/正解 面積比 | 予測/正解 箇所比 |
|---|---|---|
| 出発点（ep48） | 1.388 | 0.924 |
| シード1（ep42） | 1.475 | 0.926 |
| シード2（ep32） | 1.600 | 0.927 |
| シード3（ep38） | 1.600 | 0.973 |

面積比は +15.3%、箇所比は +5.3%。**早く止めるほど、かたまりを太らせる方に寄る。**
alpha ほど極端ではない（alpha では箇所比が逆に下がった）が、同じ非対称性がある。

**含意。** 「学習側のつまみ」は、どれも同じ一本の軸の上を動かしているだけで
あるらしい。alpha でも停止エポックでも、動くのは動作点だけで、F値は動かない。
これは `修士論文の構成.md 4.2`（改良8種がすべて同じ帯に収まる）の背景として
使える。

## 4. 帯の幅は指標と地域で 11 倍違う

| | 広島 | 島根 |
|---|---|---|
| 面積F | 0.0018 | 0.0118（6.6倍） |
| 箇所F | 0.0071 | 0.0198（2.8倍） |

最も狭い（広島 面積F 0.0018）と最も広い（島根 箇所F 0.0198）で **11倍**ある。

理由は2つ考えられるが、切り分けていない。

| | |
|---|---|
| 箇所数評価は不連続 | 1画素の増減でかたまりが結合・分裂し、被覆のしきい値を跨ぐ。画素の微小な変化が箇所数では段差になる |
| 島根は学習していない | 動作点の差がそのまま出る。広島テストは学習分布の中なので吸収される |

**実務上の帰結。** 条件を比較するときは、**その指標・その地域の帯**を使うこと。
広島の面積Fで「帯の外」でも、島根の箇所Fでは帯の中に入る差がある。

## 7. この文書で確かめていないこと

- **n=4 は少ない。** 最小–最大も ±2sd も、真の幅の下限しか与えない
- 2段目の帯は `Stage2_SAM_OL`（近傍のみ）の構成だけ。
  広域つき・土地利用つきの帯は測っていない（`6.1` はこの帯を流用している）
- **帯は同一構成でのみ有効。** 構造を変えると分散自体が変わりうる。
  オーバーラップ学習や3エンコーダの帯は測っていない
- **停止エポックの効果とシードの効果を分離していない。** `2` の単調性は
  n=4 の偶然かもしれない。切り分けるには同一シードで停止エポックを
  変えた評価（保存した重みが無いので再学習が要る）が必要
- **帯が指標で 11 倍違う理由を切り分けていない**（`4` の2説）
- 島根は全24,569タイルで、広島テストは2,964タイル。
  **タイル数の差が帯の広狭に効いている可能性**を見ていない
  （母数が多い島根の方が広いので、統計誤差では説明できない方向ではある）
- 出発点はシード未固定（`torch.manual_seed` が無い）。
  **4本のうち1本だけ生成過程が違う**
- 全条件のうち**固定されているのは12本だけだった**（`8`。2026-10-29 に調べた）

## 8. **乱数の固定は56本のうち12本だけだった**（2026-10-29）

`7` の最後に「出発点はシード未固定」と書いてあったが、**それが出発点
だけの話ではなかった。** 全ノートブックを調べた。

| | 件数 | 中身 |
|---|---:|---|
| `torch.manual_seed` **あり** | **12** | `FCN` / `PSPNet` / `DeepLabV3` / `SegFormer` / `MLPDecoder`（**`27` の4族比較**、seed 42）、`seed1/2/3`（1/2/3）、`bg30` / `bg50` / `bg10_ASPPStride4` / `OL_LogitHinge`（42）|
| **なし** | **44** | `AttentionUNet`(3) / `EarlyFusionUNet`(2) / `MiddleFusion`(2) / `FinalFusion_SAM_APM` / `FinalFusion_DEM_APM` / `TransUNet` / `Triple_UNet`、**`OverlapTrain` 5本すべて**、ほか |

**第3章・4.2 の中心の比較は、固定なしの側にある。**
つまりそれらの条件は、重みの初期値と DataLoader のシャッフル順が
OS のエントロピー由来で、**同じノートブックを回し直しても再現しない。**

### 8.1 データのほうは揃っている

| | |
|---|---|
| 同一の分割 | 56件のうち **53件**が `6:2:2 / test_size=0.2→0.25 / random_state=42` |
| 旧プロトコル | 2件（`8:2`・検証分割なし。既知の欠陥）|
| 意図的に別 | 1件（空間ブロック20km角）|

`train.random_state` を上書きしている config は**1つもない**
（`dc5lib/traincfg.py` の既定 42 がそのまま効いている）。

> **だから「同じデータに対して比較した」は成り立つ。**
> 成り立たないのは「**同一 seed で**比較した」である。

### 8.2 道具は作ってあったが、錨が狭くて黙って飛ばしていた

`tools/wire_config.py` の `_add_seed` が固定を入れる。docstring に
「どのノートブックも `torch.manual_seed` を呼んでいなかった（29件すべて）」
と書いてあるので、**気づいて道具を作ったが、一部にしか流れていなかった。**

原因は錨が `"model = build_model(get(CONDITION).arch)"` という
**閉じ括弧まで含む1行の文字列**だったこと。

    model = build_model(get(CONDITION).arch,      # 引数が続いて改行する → 当たらない
    model = build_model_for(get(CONDITION))       # 3入力の条件     → 当たらない

**戻り値が「直した内容なし」になるだけなので、気づけなかった。**
正規表現 `^model\s*=\s*build_model(?:_for)?\(` に替え、呼び出し側の
ゲートも同じ規則にした。4つの書き方に当たり、
`    model = MultiEncoderUNet(...)`（字下げ・直書き）には当たらないことを
確かめてある。

### 8.3 **どうしたか — 未学習のものだけ固定した**

既存44本に固定を入れても、**いまある重みは固定前に学習したもの**なので
再現できるようにはならない。再学習は U-Net 系の比較だけで10本以上、
`OverlapTrain` を含めると15本以上になる。**そこで未学習のものだけ直した。**

`wire_config.py` は既定で学習済みを飛ばすので `--all` でそれが済む。
対象は4件（`FullSkipSup` / `bg10_FullSkip` / `bg10_FullSkipSup` /
`bg10_FullSkipSupASPP`）で、どれも `c17` に
**乱数の固定**と `if __name__ == "__main__"` ブロックの削除が入った。

- `UNet_SAM_InstLoss` は**残っている**。`model = UNet()` と直書きで
  `build_model` を通っていないので、`wire_config.py` の対象外。
  回すなら先に `build_model` 化が要る
- `bg30` / `bg50` / `bg10_ASPPStride4` は未学習だが**固定済み**だった

### 8.4 論文の書き方

**「同一 seed で比較した」とは書けない。** 書けるのはこうである。

> 全条件を**同一のデータ分割**（6:2:2、`random_state=42`）で学習し、
> **差はゆらぎ幅で判定した**。ゆらぎ幅は同一構成の学び直し4本の
> 散らばりとして測った（`4`）。

**判定の方法は無事である。** 帯はまさに「学び直したときにどれだけ
動くか」として測った量なので、条件ごとに初期値が違うことは
**帯が吸収している**。しかも `2` で分かったとおり
**ゆらぎの正体はシードではなく停止エポック**（検証F最良が 32〜48 の
どこに落ちるか）なので、固定しても帯は大きく縮まらないと見ている。

> ただし**これは「固定しなくてよい」という話ではない。**
> `2` の単調性は n=4 で、`7` のとおり**停止エポックの効果と
> シードの効果を分離できていない。** 分離には同一シードで
> 停止エポックを変えた評価が要り、それには再学習が要る。
