付録：結果集約ツール ModelComparison

やっていること

  • 各モデルフォルダのノートブックの保存済み出力から、Recall / Precision / F値と混同行列を抽出
  • フォルダ名から実験条件（拡張の有無・入力・融合方式）を解釈し、ノートブック内の実装クラスと食い違っていないか照合
  • 条件を横断した比較表（CSV / JSON）とグラフを出力

設計上のポイント

  • 評価セルの判別は print のラベルではなくソースコードで行う（ラベルが実態と食い違っている箇所があったため）
  • 再推論しないので、重みやデータセットがなくても動く
  • 条件フォルダを足して再実行するだけで表とグラフに反映される

既存の FSS_analysis が1条件の中でタイル単位に誤差要因を分析するのに対し、本ツールは条件どうしを横断して最終スコアを比較する。用途が違うので併用できる。
