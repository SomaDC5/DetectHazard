学習・評価の設定

学習設定

最適化Adam（lr = 1×10⁻⁴）
損失関数Focal Tversky（α=0.7, β=0.3, γ=0.75）
バッチサイズ32
エポック数1,000（デュアル入力条件）
モデル選択検証データの F値が最良のエポック
Dropout0.25（ボトルネック前） / 0.5（後）

データ拡張（該当条件のみ）

学習データにのみ、地形量・航空写真・マスクへ同一のパラメータで適用する。

  • ランダム回転　±15°
  • 平行移動　±10 %
  • 拡大縮小　0.8 〜 1.2 倍
  • 左右・上下反転　各 50 %

マスクは最近傍補間、画像は双線形補間。

損失は α > β とすることで見逃し（False Negative）の罰を相対的に軽くせず、再現率を優先する設定。クラス不均衡（陽性 約9 %）への対処も兼ねる。
