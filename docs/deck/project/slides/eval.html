EVALUATION

評価方法

通常評価（面積評価）

出力マスク 128×128 の全画素を正解と比較し、TP / FP / FN / TN から Recall・Precision・F値を求める。

境界評価

四辺から 16 px（各辺 12.5 %）を除いた中心 96×96 のみで同じ指標を計算する。畳み込みでは画像端の画素が周囲情報を参照できず精度が落ちる、という仮説を検証するための指標。

Recall（再現率）

実際の警戒区域のうち、正しく抽出できた割合。見逃しの少なさ。本研究で最重視する。

Precision（適合率）

抽出した領域のうち、実際に警戒区域だった割合。過検出の少なさ。

F値

Recall と Precision の調和平均。クラス不均衡下での総合指標として用いる。

各条件について 広島 / 島根 × 通常 / 境界 の 4 通りを算出し、14条件 × 4 = 56 件の結果を横断比較した。
