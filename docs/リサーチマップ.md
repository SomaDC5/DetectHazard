### なぜこの題材か

2頁しかないので1トピックに絞る。**ロジット刈り取りが最も収まりがよい。**

| | |
|---|---|
| 話が短くて済む | 「確率にすると情報が消えるので、確率にする前の値で判定する」の一行 |
| 数字が明快 | 箇所F 0.7023 → 0.7397（+0.0374）。**学習が1回も要らない** |
| SCIS の続きになる | SCIS で飽和の診断まで書いた。その診断を逆手に取る話 |
| 県をまたいでも効く | 広島で決めたしきい値 29.150 をそのまま島根に当てて +0.0259 |

**ゆらぎ幅も一緒に入れる。** 「帯を測ったうえで差を論じる」という作法は
2頁でも書ける（広島 箇所F 0.0071 に対して +0.0374 は 5.3倍）。

## 5. 発表3 — FSS 2027（第43回・2027年9月頃）

**題材: 出力の統合による再現率の改善と、前段と後段で買うものを分ける原理**

| | |
|---|---|
| 形式 | 査読あり。本研究の主結果をここに置く |
| 申込 | 5月頃（推定。FSS2026 は当初5月22日） |
| 開催 | 9月上旬（推定。FSS2024 は 9/2〜4、FSS2025 は 9/3〜5、FSS2026 は 9/2〜4） |

### 中身

| 節 | 内容 | 数字 |
|---|---|---|
| 1 | オーバーラップ学習と推論。併用が超加法的 | 箇所R +0.0844 / +0.0747 → 実測 +0.1654 |
| 2 | ロジット刈り取りと後段CNN | 0.7071 → 0.7397 → 0.7525 |
| 3 | **和集合アンサンブル。見逃しは入力の違う条件で重ならない** | Jaccard 0.4766。**3本で折り返す** |
| 4 | **合意数チャネル。前段の内側に存在しない量** | AUC 0.8220 > ロジット最大値 0.8191。箇所F +0.0079 |
| 5 | **払う通貨を分ける原理** | 和集合は刈り取りの取り分を 1.7倍に、ヒンジは半分にした |
| 6 | 県をまたいだ汎化 | 島根 0.4820 → 0.6247 |

**この構成の価値は「効いたもの」と「効かなかったもの」が同じ原理で説明できる点である。**
広域の文脈・土地利用・ロジットヒンジ・分割の後段はいずれも効かなかったが、
**どれも「刈り取りが既に供給しているものを前倒しで買っていた」**と言える。

**第8章の性格が決まっている。**
`展望_再現率をどう上げるか.md 15.7` と `19.5` で、
「残りがどこにあるか」の候補を順に潰した。

| 候補 | 状態 |
|---|---|
| もっと広い文脈 | 潰れた（AUC +0.000） |
| 前段が見ていない情報 | 潰れた（土地利用 AUC +0.004） |
| 分割の後段 | **潰れた**（上限が刈り取りの17%） |
| そもそも刈れない | **残った** |

上限 箇所F 0.9199 に対して 0.7784 で止まっており、
その差が**手法の限界ではなく課題の限界**（正解データ自体の揺らぎ）である
可能性を D で検証する。**ここが第6章と第8章をつなぐ。**

## 10. この計画で確かめていないこと

- **FSS 2027 の日程は未公表**（2026年10月時点）。`7` は過去3回からの推定
- **SCIS&ISIS 2028 の日程も未公表。** 隔年という前提に依っている
- 指導教員の意向（どの学会を狙うか、年に何回出すか）を反映していない
- C・D の評価指標を帯に合わせて決めていない（島根 箇所F の帯 0.0198 は広い）
- D（建物データ）は基盤地図情報のダウンロードにユーザ登録が要る。
  整備範囲が地域で違う（都市計画区域は縮尺2500、それ以外は25000）ので、
  広島・島根がどちらかを確認していない
- 情処の学生セッションの形式（2頁・現地発表）は個人のメモから得た情報で、
  **公式ページで確認していない**
