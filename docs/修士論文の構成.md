## 1. 第一章について

### 1.1 他のモデルとの比較は 1〜2本で足りる

構成案の狙いは「精度差が小さいので改良しやすい U-Net を選んだ」という理由づけ。
これは手元の証拠と**整合的**である。

| 構造 | パラメータ | 広島 面積F | 広島 箇所F |
|---|---|---|---|
| Early 融合 | 31.04M | 0.6363 | 0.6023 |
| Middle 融合 | 44.28M | 0.6721 | 0.6547 |
| Final 融合 | 43.58M | 0.6727 | 0.6506 |
| Attention | 44.29M | 0.6763 | 0.6545 |
| **TransUNet** | **94.03M** | **0.6728** | 0.6459 |

**Transformer 系で 94M（Final の2.2倍）あっても 0.6728 で同じ。**
アーキテクチャ族を跨いでも同じ帯に入る例が、すでに1つある。

ただし「SegFormer も同じ」と主張するには実際に回す必要がある。
**3〜4本は多い。1〜2本に絞ってよい。**
目的は「族を変えても帯に入る」ことを示すことで、網羅ではない。

### 1.2 「検出傾向の差」には別の材料がある

タイルごとのF値の順位相関（153組）。

| | Early | Middle | Final | Attention | TransUNet |
|---|---|---|---|---|---|
| Early | 1.000 | 0.778 | 0.753 | 0.766 | 0.776 |
| Middle | 0.778 | 1.000 | 0.846 | 0.851 | 0.842 |
| Final | 0.753 | 0.846 | 1.000 | 0.866 | 0.850 |
| Attention | 0.766 | 0.851 | 0.866 | 1.000 | 0.874 |
| TransUNet | 0.776 | 0.842 | 0.850 | 0.874 | 1.000 |

**Early は他のどれとも最も相関が低い**（0.753〜0.778）。
精度が低いだけでなく、**違う間違い方をしている**と言える。

さらに重要なのは、全体で最も相関が低いのが
**DEM系 ↔ SAM系（0.596〜0.615）**であること。
**構造を変えるより入力を変えたほうが多様性が出る。**
これがそのまま第二章（アンサンブル）への橋渡しになる。

## 2. 保留されていた3点

### 2.1 モデル改良が効かなかったこと — 落とさない

| 施策 | 広島 面積F | 判定 |
|---|---|---|
| 構造改良8種（深層監督・監督Attn・ASPP・ストライド・全スケール結合ほか） | 0.6636〜0.6776 | すべて帯の中（±0.01） |
| データ拡張 | 0.6996 | +0.025 |
| **アンサンブル（4条件）** | **0.7200** | **+0.047** |
| **オーバーラップ学習＋推論** | 箇所F **0.7071** | 箇所F **+0.056** |

**効かなかったことが主張になるのは、原因を特定しているから。** 材料は揃っている。

| 診断 | 値 |
|---|---|
| 失敗タイルの 61% は正解が全部タイル外周16px帯にある | 対照は 10.7% |
| ASPP で補助ヘッド単体は +0.119 改善、本体は +0.009 | デコーダがスキップを使っていない |
| エンコーダの活性コントラストは失敗タイルでも同等以上 | enc2 1.04倍 / enc3 1.37倍 |
| 出力が飽和（確率 0.02 未満が 90.69%） | しきい値では再現率を動かせない |

### 2.2 オーバーラップ学習と、広島・島根の2テスト

広島はタイル単位のランダム分割なので、**空間的自己相関で甘く出る**。
前報でも「同一地域内での精度として解釈すべき」と断っていた点である。
島根は県をまたいだ評価で、学習タイルは0枚。

**ブロック分割を1本だけ回すと3点が並ぶ。**

```
ランダム分割 0.6727 ／ ブロック分割 ? ／ 島根 0.5381
```

「広島は同一地域内の精度、島根は県をまたいだ精度、その中間がブロック分割」
という位置づけが実測で示せる。**断り書きが実測に変わる。** 学習1回で済む。

> ただし広島は危険区域の密度が地域で2倍近く違う（経度方向で 27.3% 〜 43.3%）。
> 23km角ブロックで 6:2:2 に割ると正例率が 学習 2.63% / テスト 1.45% と揃わない。
> **比較用ではなく、自己相関の大きさを測る診断として**位置づけること。

### 2.3 正解データ自体の見逃し — 当初の目的そのもの

前報の「はじめに」に次の記述がある。

> 人手によるスクリーニングで見落とされ得る危険な斜面を明らかにできる

つまり「誤検出の一部は、手法の誤りではなく**正解データの見逃しを拾った**もの」
という話は、**弱点ではなく価値の主張**になり得る。

**ただし現状のデータでは区別できない。** ここは限界として正直に書く。

検証する道はある。誤検出領域について**傾斜と保全対象（建物）の有無**を調べ、
「指定基準を満たすのに未指定」の割合を推定する。
失敗タイルの 60% が「正解領域のほうが周囲より緩斜面」（中央値 −1.410度）
だったことの裏返しで、**地形的には危険だが未指定**の斜面がどれだけあるかを見る。
建物・土地利用データが要る。

## 3. SHAP / Grad-CAM について

**新しい道具を足す前に、既にある材料で相当書ける。**

| 既にあるもの | 何が言えるか |
|---|---|
| タイル別F値の相関行列（153組、すべて 0.9 未満） | どの条件とどの条件が違う間違い方をするか |
| 選択型アンサンブルの天井（+0.0744〜+0.1769） | タイル単位では条件間に大きな差がある |
| 失敗タイルの層別（外周・傾斜・サイズ） | どういうタイルで失敗するか |
| 各段の活性コントラスト | 情報がどこまで保たれているか |
| Attention ゲートの係数 | どのブランチがどこを見ているか |
| 入力 ablation（SAMのみ 0.5688 → SAM+APM 0.6727） | 航空写真の寄与 |

最後の行が**実質的に SHAP と同じこと**をしている。
チャネル単位の寄与なら ablation のほうが安価で解釈も明快。

Grad-CAM を足すなら、漠然と可視化するのではなく**具体的な問いに当てる**。

- Early 融合はなぜ劣るのか（相関も最も低い）
- DEM系と SAM系はなぜ違う間違い方をするのか（相関 0.596）
- オーバーラップ学習は本当に境界を見るようになったのか

## 6. まだ無いもの

| 項目 | 必要なもの | 優先 |
|---|---|---|
| **複数シード** | 学習3本程度 | **高**。0.005 の差を「差が無い」と言い切る前提 |
| SegFormer 等の比較 | 学習1〜2本 | 中。第2章の理由づけに要る |

| 正解データの見逃しの定量化 | 建物・土地利用データ | 中。第5章の目玉になり得る |
| Grad-CAM | 実装 | 低。問いを絞れば価値あり |
| オーバーラップ学習のアンサンブル | 学習（DEM+APM 版は条件作成済み） | **高**。第4章の締めになる |

**複数シードが地味に重要。** いま論文に書く差の多くは1シードの値である。
アンサンブルの +0.047 やオーバーラップの +0.084 はゆらぎ幅（0.003〜0.005）の
10〜17倍あるので符号は信じてよいが、**構造改良の ±0.005 を「差が無い」と
言い切るには、ばらつきそのものを測っておくほうが安全。**
