# legacy_scripts について

このフォルダのスクリプトは、4条件（DEM単一・SAM単一・DEM＋APM・SAM＋APM）を
それぞれ個別に手探りで解析していた際の元スクリプト（`analyze_*.py`）と、
正規化方法を確定させるために使った検証用スクリプト（`verify_*.py`）です。

現在はこれらの内容を `../lib/` 以下の共通ライブラリと `../run_analysis.py` に
整理・統合済みです。新しい解析には `run_analysis.py` と `compare_conditions.py`
を使ってください。このフォルダは、どのような試行錯誤を経て正規化方法や
データセットの対応関係を特定したかの記録として残しています。
