# FSS_analysis（参考実装）

前任の解析プログラム。外付けSSD `Soma_SSD` の `FSS_analysis/` にだけ置いてあり
版管理されていなかったので、**コードとREADMEだけ**をここに取り込んだ。

**このフォルダは動かすためのものではない。** いまの解析は `analysis/` を使う。
残してあるのは、こちらにしかない着眼点があるため。

生成物（比較画像のPNG数百枚、`error_stats.csv`、`compare_output/`）は
容量が大きいので取り込んでいない。元のSSDに残っている。

## いまの `analysis/` との関係

目的はほぼ同じ（保存済み重みで推論をやり直し、タイル単位で誤差を分解する）。
`analysis/` は独立に作ったものだが、結果的に多くが重なっている。

**`analysis/` にあって、こちらに無いもの**

- 箇所数評価（被覆方式）
- 地域をまたいだ比較、テスト集合の構成を揃えた再集計
- 同じタイル上での条件どうしの対比較（Wilcoxon検定つき）
- Attention Gate の注意係数の抽出
- 条件を `experiments/*/config.yaml` から自動で拾う（こちらは `lib/conditions.py` に手書き）

**こちらにあって、`analysis/` に無いもの（取り込む価値がある）**

1. **タイルの自動分類** — 「良好 / 見逃し優勢 / 過検出優勢 / その他」に振り分ける。
   いまは連続値の F値しか出しておらず、「どの失敗の仕方か」で数えられていない。

2. **誤差の大きいタイルの比較画像を自動出力** — 入力 / 正解 / 予測 / 誤差マップを
   並べた PNG を、worst_FN・worst_FP・good ごとに書き出す。
   定性評価をスライドに載せるとき、いまは手作業で抜き出している。

3. **航空写真の明度・緑色度をタイル特徴量にしている** — `analysis/features.py` は
   傾斜・起伏・正解の形しか見ていない。「植生が濃いところで外しやすいか」を
   直接測れるので、航空写真が何を補っているかの分析に効くはず。

3番目は、これまでの解析で「航空写真の併用が最も効く」「効くのは急斜面の場所」
までは分かったが、**写真の何が効いているか**には踏み込めていない。
明度・緑色度を特徴量に入れれば、そこを一段掘れる。

取り込むときは `lib/error_analysis.py` を読むのが早い。
